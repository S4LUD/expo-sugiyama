High-performance native hierarchical (Sugiyama) graph layout computation for
React Native (Expo Modules).

## Overview

Computes layered graph layouts entirely in native code, off the JS thread:

1. **Layering** — longest-path rank assignment
2. **Ordering** — median-heuristic cross-minimization
3. **Coordinates** — subtree-width allocation, parent centering, rank rows

The algorithm is a strict port of the JS reference
(`mobile/src/features/layout-engine/`) and is mirrored bit-for-bit across
Android (Kotlin) and iOS (Swift). Output is deterministic for identical input.

## Installation

```bash
npx expo install expo-sugiyama
```

The native module is autolinked on both platforms (`ExpoSugiyama`).

## Usage

```ts
import { computeLayoutAsync } from 'expo-sugiyama';

const result = await computeLayoutAsync(
  [
    { id: 'a', width: 150, height: 64 },
    { id: 'b', width: 150, height: 64 },
    { id: 'c', width: 150, height: 64 },
  ],
  [
    { id: 'e0', source: 'a', target: 'b' },
    { id: 'e1', source: 'b', target: 'c' },
  ],
  { nodesep: 60, ranksep: 80, marginx: 40, marginy: 40 }
);

// result: { positions: { a: {x, y}, ... }, width, height, skipped: [] }
```

### Options

| Option           | Default | Description                          |
| ---------------- | ------- | ------------------------------------ |
| `rankdir`        | `'TB'`  | `'TB' \| 'BT' \| 'LR' \| 'RL'` (accepted; layout is top-to-bottom) |
| `nodesep`        | derived | Same-rank spacing; when unset, `0.2 × nodeWidth`, composition-independent |
| `ranksep`        | derived | Between-rank spacing; when unset, `0.5 × nodeHeight` |
| `marginx`        | `40`    | Canvas horizontal margin             |
| `marginy`        | `40`    | Canvas vertical margin               |
| `nodeWidth`      | `150`   | Default node width                   |
| `nodeHeight`     | `64`    | Default node height                  |
| `orderingPasses` | `4`     | Cross-minimization passes            |
| `cyclePolicy`    | `'tolerant'` | `'tolerant' \| 'throw'`       |

### Errors

- `CYCLE_DETECTED` — cycle found with `cyclePolicy: 'throw'`
- `INTERNAL` — unexpected native failure

Invalid nodes/edges never throw: they are skipped and reported in
`result.skipped`.

## Testing

- **iOS:** `swift test` from `ios/` (SwiftPM harness over `Layout/` + `Tests/`),
  or the podspec test spec via `pod lib lint --test-specs=Tests`
- **Android:** `./gradlew testDebugUnitTest` from `android/`
- **Parity:** every fixture in `fixtures/` (generated by the JS reference) must
  match bit-for-bit on both platforms — see `ParityTests.swift` /
  `ParityTest.kt`
